# kondo
[Github](https://github.com/tbillington/kondo)
Утилита (CLI и GUI) для очистки дискового пространства, которая рекурсивно ищет в каталогах проекты известных типов (Rust, Node.js, Python и др.) и удаляет из них несущественные файлы вроде node_modules или target.

## Установка
```shell
tar -xzvf ./kondo-x86_64-unknown-linux-gnu.tar.gz
mv ./kondo ~/bin/
```
